# Checklist previo a integración
- Inicio, Academia, Evaluación, Laboratorio, Simulador y Biblioteca abren.
- Dos evaluaciones consecutivas generan combinaciones diferentes.
- La evaluación muestra fuente y respuesta esperada.
- El laboratorio cambia con los controles y mantiene aviso “no CFD”.
- El simulador genera escenarios y eventos variables.
- El debriefing reconstruye decisiones.
- Revisar todo contenido LOCAL contra fuentes institucionales.
- Probar escritorio y móvil.
- Integrar a la versión pública sólo después de validar.
