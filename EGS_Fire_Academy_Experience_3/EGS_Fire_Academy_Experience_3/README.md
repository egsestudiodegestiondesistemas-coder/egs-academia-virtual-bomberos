# EGS | Academia Virtual de Bomberos — Experience 3.0

Proyecto autocontenido para probar la nueva arquitectura sin tocar la versión pública.

Incluye:
- Academia por niveles.
- Evaluación dinámica por plantillas.
- Variación de preguntas y distractores.
- Laboratorio conceptual causa–efecto.
- Simulador con escenarios/eventos variables.
- Decisiones y consecuencias.
- After Action Review.
- Progreso local sin cuenta.
- Biblioteca y trazabilidad.

IMPORTANTE: los módulos marcados `LOCAL` son estructura demostrativa. Deben completarse y validarse contra el corpus institucional antes de presentarlos como doctrina oficial.

## Ejecutar en Windows
Abrí PowerShell dentro de esta carpeta y ejecutá:

    py -m http.server 8080

Después abrí:

    http://localhost:8080

También podés ejecutar `INICIAR_EGS.ps1`.

No requiere instalar paquetes Python.
